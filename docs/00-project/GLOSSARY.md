# GLOSSARY.md

- **Evento**: Ocasião única (ex.: aniversário do Martin) que agrupa todas as fotos, molduras e configurações.
- **Convidado**: Usuário que acessa a página do evento via QR Code; não necessita login.
- **Fotografia**: Imagem capturada ou selecionada pelo convidado, que será armazenada e exibida na galeria.
- **Moldura**: Sobreposição gráfica temática (fazendinha) aplicada à fotografia antes do upload.
- **QR Code**: Código bidimensional que contém a URL pública do evento e direciona o convidado ao site.
- **Galeria**: Visualização pública das fotografias aprovadas para o evento.
- **Admin / Usuário Administrador**: Conta protegida que gerencia fotos, molduras, estado do evento e políticas.
- **Supabase**: Plataforma Backend‑as‑a‑Service (BaaS) que fornecerá banco de dados PostgreSQL, storage e Row‑Level Security.
- **RLS**: Row‑Level Security – mecanismo de controle de acesso no Supabase.
- **Canvas API**: API nativa do navegador para manipular imagens (redimensionamento, aplicação de molduras, remoção de EXIF).
- **MVP**: Produto Mínimo Viável – conjunto de funcionalidades que permite a experiência básica da festa.
- **Rate Limiting**: Controle de quantidade de requisições por unidade de tempo para prevenir abuso.
- **EXIF**: Metadados de foto que podem incluir localização, data e informações do dispositivo.
