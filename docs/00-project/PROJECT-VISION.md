# Visão do Projeto

**Fazendinha do Martin — Galeria Digital**

Prover uma experiência digital simples, divertida e segura para que os convidados do aniversário de 2 anos do Martin possam registrar fotos, aplicar molduras temáticas da fazenda e compartilhar suas lembranças, tudo acessível via QR Code em dispositivos móveis, sem necessidade de login ou instalação de aplicativo.

A solução será construída como um site estático/mobile‑first hospedado no Vercel, usando Next.js, React e TypeScript, com armazenamento de arquivos e regras de acesso implementadas no Supabase (a serem configuradas nas fases posteriores).
