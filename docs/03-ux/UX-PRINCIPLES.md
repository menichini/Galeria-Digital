# UX-PRINCIPLES.md

## 1. Simplicidade Extrema (Frictionless)
O público-alvo são convidados da festa (família, amigos, pessoas de todas as idades). A interface deve ter o mínimo absoluto de atritos:
- Nenhum login, nenhuma criação de conta.
- Apenas botões grandes e chamativos.
- Textos curtos e diretos (ex: "Tirar Foto", "Enviar").

## 2. Temática Imersiva (Delightful)
A interface deve ser uma extensão da festa. O tema "Fazendinha do Martin" (cores, ícones, elementos lúdicos) deve estar presente sem poluir a navegação. Uso de cores alegres, bordas arredondadas e feedback visual agradável (micro-interações ao clicar e fazer upload).

## 3. Feedback Imediato
Os usuários devem sempre saber o que está acontecendo:
- Se a câmera não abrir, mostrar uma mensagem clara de como resolver ou usar upload local.
- Durante o upload, mostrar um "loading" temático (ex: um tratorzinho se movendo).
- Mensagem clara de sucesso no final.

## 4. Previsibilidade
Ao visualizar a moldura sobre a foto, o resultado final (download) deve ser **exatamente igual** ao que o usuário está vendo na tela (WYSIWYG - What You See Is What You Get).
